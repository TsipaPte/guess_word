# Угадывание слов

Данный проект представляет собой мини игру в терминале (TUI), суть которой угадывать слова по мотивам игры "Висилицы". Помимо этого, также есть множество других полезных функций: чёткое разделение ролей на владельца, администратора и обычного пользователя, ранги, настройки аккаунта и так далее

## Установка

Этап установки разбит на логические шаги. Чтобы у Вас всё получилось, пожалуйста, чётко следуйте инструкциям ниже:

### Шаг 1: скачайте исходный код

Перейдите на вкладку с [релизами](https://github.com/TsipaPte/guess_word/releases), выберите последний и скачайте архив с исходным кодом. Полученный архив распакуйте и положите в удобное для Вас место

### Шаг 2: единоразовые команды

Данные команды выполняются только единожды, при установке проекта. Но перед тем как продолжить, попрошу Вас перейти в папку, которую Вы скачали в шаге 1 и открыть в ней терминал (или командную строку)

#### Команды для Windows

```sh
py -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
cd src
py init_db.py
```

#### Команды для macOS или Linux

```sh
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cd src
python3 init_db.py
```

#### Объяснение команд

Этот шаг не обязателен к прочтению, но если Вы хотите понять что за команды мы выполняли, то рекомендуем изучить данный раздел

1. **Команда `py -m venv venv` (для Windows) или `python3 -m venv venv` (для macOS / Linux)**: создаёт виртуальное окружение. Если простыми словами, то когда Вы устанавливаете необходимые библиотеки для работы программы, они установятся в изолированную среду (если Вы выполнили эту команду) или напрямую в систему. Использование изолированной среды (виртуального окружения) считается лучшей практикой, нежели установки напрямую, потому что это исключает риск конфликтов и возможных ошибок
2. **Команда `.\venv\Scripts\activate` (для Windows) или `source venv/bin/activate` (для macOS / Linux)**: активирует виртуальное окружение, созданное нами в шаге 1
3. **Команда `pip install -r requirements.txt`**: эта команда устанавливает все необходимые библиотеки для работы программы. Опять же таки если по простому: программисты очень часто при разработке программ не пишут огромные части кода вручную, а берут уже готовые и проверенные временем решения. Это и есть библиотеки
4. **Команда `cd src`**: переход в папку `src`. Ничего особенного здесь нет. Это как если бы вы нажали два раза по папке в проводнике
5. **Команда `py init_db.py` (для Windows) или `python3 init_db.py` (для macOS / Linux)**: запускает скрипт который настроит базу данных. В процессе настройки он попросит у Вас логин и пароль для самого первого аккаунта - владельца

### Шаг 3: запуск проекта

Если Вы дошли до этого шага, то проект полностью установлен и теперь рассмотрим только те команды, которые нужно выполнять **каждый раз при запуске проекта**. Опять попрошу Вас зайти в папку с проектом и открыть в ней терминал (или командную строку)

#### Для Windows

```sh
.\venv\Scripts\activate
cd src
py main.py
```

#### Для macOS или Linux

```sh
source venv/bin/activate
cd src
python3 main.py
```

#### Объяснение команд

Давайте опять рассмотрим за что отвечает каждая команда (по желанию):

1. **Команда `.\venv\Scripts\activate` (для Windows) или `source venv/bin/activate` (для macOS / Linux)**: запускает виртуальное окружение, которое мы создали ещё при первичной настройке проекта
2. **Команда `cd src`**: переход в папку с кодом программы - `src`
3. **Команда `py main.py` (для Windows) или `python3 main.py` (для macOS / Linux)**: запускает сам проект
